# 06: Preserve accurate progress through checklist changes

**Milestone:** M5

**What to build:** Learners keep completed work when an administrator clarifies or reorganizes tasks, while new and removed obligations change progress predictably.

**Blocked by:** 02: Reorder tasks and move them between onboarding stages; 04: Complete and revisit a role checklist privately

**Status:** ready-for-agent

**Progress:** in-progress

- [ ] Rename, instructions edits, reorder and stage movement preserve completion for the same task identity.
- [ ] New task identities begin incomplete; removed tasks no longer display, count or appear among next tasks.
- [ ] Deleting and creating a new obligation cannot reuse an old completion through text, index or recycled identity.
- [ ] Reconcile progress using the current saved checklist; do not reset the whole role merely because its revision changes.
- [ ] Demonstrate an administrator editing a checklist while a learner has saved completion, then assert current counts and ordering.
- [ ] Preserve browser/role isolation and accurate behavior across reload.
