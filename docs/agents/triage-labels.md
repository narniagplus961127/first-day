# Triage labels

- needs-triage: requires evaluation.
- needs-info: requires more information.
- ready-for-agent: specified and ready for agent implementation.
- ready-for-human: requires human implementation.
- wontfix: will not be implemented.

Record the applicable label in each issue's Status field. Record lifecycle completion separately in Progress, following issue-tracker.md. A Status of ready-for-agent with Progress resolved means completed work, not an active ticket.
