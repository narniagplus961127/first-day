# Lumen HR onboarding

This is a fictional Lumen exercise. It does not describe the FirstDay repository, a real employer or actual employees. Work only with invented examples; this guide does not establish employment entitlements or provide legal advice. Nothing in this exercise sends messages or changes real personnel records.

## Before you start: orientation and resources

Read this guide once, then locate the fictional directory People Sandbox / Resources. In this exercise that directory groups WELCOME-01, the orientation outline, privacy guidance, the FAQ and the onboarding summary. These are sample resource names, not links to an actual company workspace. People Guide is a fictional team alias, not an actual person or email address.

## Day 1: welcome template and orientation

WELCOME-01 requires Role / First-day plan / Resource links / Questions. Its resource directory is People Sandbox / Resources. For the welcome-template task, make a local practice copy and fill those four headings with invented details for Demo Joiner A. Use the fictional role HR, list the orientation sections as the first-day plan, reference the sample directory and leave an explicit question about anything unclear.

Prepare an orientation outline with three sections: Welcome, Resources and Practice walkthrough. Welcome introduces the fictional exercise and the learner's selected role. Resources points to People Sandbox / Resources and WELCOME-01. Practice walkthrough follows a checklist task, reads its guide and marks the practice task complete. This outline is a draft exercise, not a scheduled event or a message to a real joiner.

## Day 1: privacy practice

Use invented participant labels such as Demo Joiner A. Never put real addresses, identification numbers, credentials or employee personal records in the sandbox. Review each practice artifact before keeping it: check that names are invented, links describe fictional resources and no sensitive details were copied. If a real detail is present, remove it from the exercise instead of reproducing it in a question. Practice with synthetic content only.

## Week 1: FAQ and communication practice

The sample FAQ routes workspace questions to the fictional People Guide alias and technical exercise questions to the relevant role guide. If a question has no documented answer, record it as an open question. Do not infer a company policy from an example or promise an entitlement. This guide deliberately leaves employment-entitlement amounts unspecified.

Draft a fictional welcome message using the WELCOME-01 headings. Follow Draft / Check fictional details / Self-review / Keep as an unsent exercise. The details check confirms the invented participant label, fictional role and sample resource names. Self-review confirms all four template fields are present, questions are explicit and no personal data was included. Keep the result as a local unsent practice artifact; do not email, post or contact anyone.

## Week 1: review the onboarding summary

The summary template contains Resources reviewed / Questions remaining / Next practice step. Make a fictional summary that lists WELCOME-01 and the resource directory, records one remaining question without inventing its answer, and identifies one next practice task. Review it against this guide and the privacy checks. A learner can mark their practice task complete themselves; there is no manager approval or real HR record update.
