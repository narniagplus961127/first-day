## Capture context

Desktop captures use a 1440 × 1000 viewport; mobile uses 390 × 1000. All images are PNG viewport captures from the live app, not design exports or generated mockups. Only the intentionally public learner and read-only admin demo accounts were used.

The chat capture shows one real question: “What exact command starts the fictional Lumen frontend and on which port?” The returned answer cites the published Lumen Frontend Developer onboarding guide. Its command belongs to that fictional exercise, not the FirstDay repository. Generated wording and document counts may change.
